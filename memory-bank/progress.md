## Progress

**Реализовано:**
- Modbus TCP (pymodbus 3.6.x): 01–06, 15/16; запуск/остановка сервера через API; при ошибке «порт занят» — понятный ответ в API.
- API: `/health`, `/api/config`, `/api/state/{kind}` (GET/PUT), `/api/state/{kind}/batch`, `/api/server/status`, `/api/server/start`, `/api/server/stop`, `/api/profiles` (GET/POST), `/api/profiles/{slug}/load`, DELETE профиля.
- Хранилище: `config.yaml`, `state.json`, каталог `profiles/` (YAML).
- GUI:
  - Конфигурация, регистры (одиночная и batch‑запись, пресеты «Заполнить нулями», «Случайные значения»), Modbus‑сервер (статус с автообновлением, Запустить/Остановить), профили (сохранение/загрузка/удаление), при включённой авторизацией — форма входа.
  - Редизайн интерфейса: общий тёмный dashboard‑стиль (`styles.css`), единое оформление панелей, регистров и журнала событий; улучшен контраст шрифтов.
  - Сетка регистров переработана в таблицу по образцу классических Modbus‑симуляторов: строки‑диапазоны адресов с колонками `+0…+9`, редактирование только там, где это поддерживается (coils/holding).
  - Журнал событий приведён к отдельной панели по всей ширине снизу, с цветовой дифференциацией типов (запуск/остановка, ошибки, Modbus‑операции, HEX‑трейс), свежие записи сверху.
  - HEX‑трейсы запросов/ответов (`modbus_req_hex`/`modbus_rsp_hex`) включают IP клиента и унифицированный формат сообщения.
  - Добавлены события `client_connect`/`client_disconnect` для отслеживания подключений Modbus‑клиентов.
  - В GUI журнала реализованы фильтры по типам записей (Все/Modbus/Сервер/Ошибки), фильтр по IP и текстовый поиск по строке сообщения/типу, а также экспорт текущего набора записей в JSON.
- Авторизация: опциональная (env `GUI_USER`/`GUI_PASSWORD`); при заданных — Basic Auth для API и форма логина в SPA.
- Тесты: health, state, batch, server, profiles; `pytest` с временным DATA_DIR.
- README: запуск, порты, профили, пресеты, тесты.

**В планах (по желанию):** CI (GitHub Actions), e2e-тесты.
