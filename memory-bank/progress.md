## Progress

**Что уже работает:**
- Поднято FastAPI-приложение с Modbus TCP сервером на базе `pymodbus`.
- Ядро `ModbusSimulatorCore` поддерживает функции 01/02/03/04/05/06 (одиночная запись).
- HTTP API:
  - `/health` – проверка живости.
  - `/api/config` – чтение/обновление конфигурации Modbus.
  - `/api/state/{kind}` – чтение и запись регистров (для `coils` и `holding` – запись одиночных значений).
- Файловое хранилище:
  - `config.yaml` – конфигурация (автозагрузка/сохранение).
  - `state.json` – состояние регистров (автосохранение при записи).
- React SPA:
  - Экран конфигурации с редактированием и сохранением настроек.
  - Экран регистров с выбором типа, диапазона и редактированием значений.
- Docker:
  - Образы backend и frontend.
  - `docker-compose.yml` поднимает оба сервиса и общий том `/data`.

**Что можно доработать:**
- Поддержка множественной записи регистров (функции 15/16).
- Управление несколькими профилями (импорт/экспорт конфигов).
- Расширенные тесты (интеграционные, e2e GUI).
- Базовая авторизация для WEB GUI (например, один логин/пароль).
