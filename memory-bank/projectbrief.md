## Project Brief: modbud_simulator

Этот репозиторий предназначен для разработки симулятора Modbus (Modbus Simulator).

**Цели:**
- Создать репозиторий с корректной инициализацией Git и GitHub.
- Вести документацию в `memory-bank` согласно правилам Cursor.

**Текущее состояние (2026-02-12, Europe/Minsk):**
- Реализованы backend (FastAPI + Modbus TCP через pymodbus) и WEB GUI (React + Vite).
- Поддержка Modbus 01–06 и множественной записи 15/16; REST API для конфигурации, состояния регистров и управления сервером (запуск/остановка, статус).
- **Генератор сигналов:** фоновое обновление holding‑регистров по заданному сигналу (синус, пила, меандр, константа) в форматах INT16/FLOAT32/FLOAT64; конфигурация генераторов привязана к профилям; в GUI — панель под таблицей регистров, отображение генерируемого значения, неоновая подсветка (цвет настраивается), подсветка затрагиваемых ячеек в таблице регистров; автообновление значений регистров в интерфейсе.
- Docker Compose, файловый storage (config/state, profiles с полем generators), базовые тесты и тесты API генераторов/профилей; локальный запуск тестов (`pip install -e .[dev]`, `pytest`).
