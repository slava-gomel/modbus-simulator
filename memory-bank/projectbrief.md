## Project Brief: modbud_simulator

Этот репозиторий предназначен для разработки симулятора Modbus (Modbus Simulator).

**Цели:**
- Создать репозиторий с корректной инициализацией Git и GitHub.
- Вести документацию в `memory-bank` согласно правилам Cursor.

**Текущее состояние (2026-02-13, Europe/Minsk):**
- Реализованы backend (FastAPI + Modbus TCP через pymodbus) и WEB GUI (React + Vite).
- Поддержка Modbus 01–06 и множественной записи 15/16; REST API для конфигурации, состояния регистров и управления сервером (запуск/остановка, статус).
- **WebSocket Real-time:** мгновенные обновления через WebSocket (заменил HTTP polling); раздельные каналы для registers/server/generators; автоматическое переподключение; UI индикатор состояния. Начальная загрузка в App выполняется один раз при авторизации (эффект только по `authenticated`), чтобы избежать лавины запросов и гарантировать загрузку таблицы регистров.
- **Генератор сигналов:** фоновое обновление holding‑регистров по заданному сигналу (синус, пила, меандр, константа) в форматах INT16/FLOAT32/FLOAT64; конфигурация привязана к профилям; в GUI — панель под таблицей регистров, мини‑график сигнала в реальном времени (живые данные через WebSocket), отображение значения, неоновая подсветка (цвет настраивается), подсветка затрагиваемых ячеек регистров; автообновление значений в интерфейсе.
- Docker Compose, файловый storage (config/state, profiles с полем generators).
- **Тесты (170+ тестов):**
  - Backend: 99 тестов (API endpoints, encoding_utils, **полное покрытие Modbus FC01-FC06/FC15-FC16**, WebSocket)
  - Frontend: 76+ тестов (converters для всех форматов, hooks, WebSocket)
  - Локальный запуск: `pip install -e .[dev]` → `pytest` (backend), `npm test` (frontend)
