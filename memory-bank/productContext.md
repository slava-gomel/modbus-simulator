## Product Context

**Название:** `modbud_simulator`

**Назначение:**
- Инструмент для эмуляции устройств/мастеров по протоколу Modbus.
- Используется для отладки, тестирования и демонстрации систем, работающих с Modbus.

**Пользователи:**
- Разработчики и интеграторы систем автоматизации.
- Тестировщики, которым нужен управляемый симулятор Modbus.

**Опыт использования:**
- Простой запуск симуляции.
- Конфигурируемые устройства/регистры.
- Генератор сигналов для автоматического обновления holding‑регистров (синус, пила, меандр, константа) с настраиваемой подсветкой в GUI.
- Возможность расширения функциональности по мере развития проекта.
