## Active Context

**Текущий фокус (2026‑02‑12):**
- Завершение интеграции фичи «Генератор сигналов» с профилями и журналом событий: надёжное сохранение/загрузка генераторов в профилях, неизменяемый профиль `default`, улучшенный журнал.

**Реализовано:**
- Backend:
  - ModbusSimulatorCore, Modbus TCP сервер (старт/стоп через API), REST API (config, state, batch, server status/start/stop, profiles, **generators**), storage (config, state, profiles с полем `generators`), lifespan с запуском движка генераторов, опциональная Basic Auth по env, модуль `modbus_log` с буфером событий.
  - **Генератор сигналов:** `SignalGeneratorEngine` (фоновый поток), `encoding_utils` (INT16/FLOAT32/FLOAT64 в 16‑битные регистры), модели `SignalGeneratorConfig` (в т.ч. `neon_color`), `GET/PUT /api/generators`; при сохранении/загрузке профиля генераторы сохраняются и восстанавливаются в движке. Движок теперь хранит **все** генераторы (включённые и выключенные), а фильтрация по `enabled` происходит только в run‑loop — это нужно для корректного round‑trip через профили.
  - Локальный форк `patched_pymodbus_server` для IP клиента; HEX‑трейсы и события `client_connect`/`client_disconnect`.
- Frontend:
  - Конфигурация, регистры (batch, пресеты), Modbus‑сервер, профили; **панель «Генератор сигналов»** под таблицей регистров: список генераторов, форма (тип сигнала, формат, адрес, амплитуда, частота, цвет подсветки — по умолчанию синий; поле цвета в стиле приложения без серой рамки), колонка **«График»** — мини‑график в реальном времени, отображение значения, неоновая подсветка. Числовые поля формы генератора редактируются как регистры: буфер ввода, проверка по blur; при невалидном значении подставляется значение по умолчанию.
  - **Автообновление** значений регистров в таблице (1.5 с); опрос значений генераторов ~120 мс для живого графика и ячейки «Значение».
  - **Подсветка в таблице регистров:** ячейки holding‑регистров, затрагиваемые включённым генератором, подсвечиваются неоном (цвет генератора).
  - Журнал событий: фильтры по Modbus/серверу/генераторам/**профилям**/ошибкам, поиск и фильтр по IP, экспорт; фильтры (кроме «Все») можно комбинировать — кнопки работают как двухпозиционные тумблеры.
  - **Логирование генераторов и профилей:** при создании/редактировании/удалении/включении/выключении генератора пишутся события `generator_*` с полной конфигурацией; при сохранении/обновлении/загрузке профиля — `profile_save/profile_update/profile_load`; при загрузке профиля для каждого генератора дополнительно пишутся `generator_load` и `generator_enable`/`generator_disable` по сохранённому состоянию.
  - **Профили:** панель профилей с неизменяемым `default`, возможностью обновить профиль из текущей конфигурации, подсветкой текущего профиля и отображением его в панели сервера; генераторы профиля корректно round‑trip'ятся даже при добавлении/удалении между загрузками.
- Тесты: health, state, batch, server, profiles, **generators API**, round‑trip генераторов через профили.

**Дальше по желанию:** CI (GitHub Actions), e2e‑тесты, доработка UX.
