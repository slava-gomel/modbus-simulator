## Active Context

**Текущий фокус:**
- Симулятор в рабочем состоянии: Modbus TCP (01–06, 15/16), профили, пресеты регистров, управление сервером, автообновление статуса, обработка ошибки порта, опциональная простая авторизация, детальный журнал событий в GUI.

**Реализовано:**
- Backend: ModbusSimulatorCore, Modbus TCP сервер (старт/стоп через API), REST API (config, state, batch, server status/start/stop, profiles), storage (config, state, profiles), lifespan вместо on_event, обработка «порт занят» при старте сервера, опциональная Basic Auth по env, модуль `modbus_log` с буфером событий и HEX‑трейс через `request_tracer`/`response_manipulator`.
- Frontend: конфигурация, регистры (одиночная и batch запись, пресеты «нули»/«случайные»), блок Modbus-сервер (статус, Запустить/Остановить, автообновление статуса), профили (сохранение/загрузка/удаление), при включённой авторизации — форма входа, журнал событий с цветовой дифференциацией типов (старт/стоп, ошибки, Modbus‑операции, HEX‑запросы/ответы, последние записи сверху).
- Тесты: health, state API, batch, server API, profiles API; conftest с временным DATA_DIR.

**Дальше по желанию:** GitHub Actions (CI), расширенные тесты/e2e.
