## Active Context

**Текущий фокус работы:**
- Стабильная работа симулятора: один Modbus TCP slave (01/02/03/04/05/06, 15/16), WEB GUI с конфигурацией, регистрами и управлением сервером (запуск/остановка, статус).

**Состояние реализации:**
- Backend:
  - `ModbusSimulatorCore` с одиночной и пакетной записью (15/16).
  - Modbus TCP сервер (pymodbus), управление потоком: старт при запуске приложения, остановка/запуск через API.
  - REST API: `/api/config`, `/api/state/{kind}` (GET/PUT), `/api/state/{kind}/batch` (PUT), `/api/server/status`, `/api/server/start`, `/api/server/stop`.
  - Файловый storage, автотесты (в т.ч. batch), версия pymodbus зафиксирована (3.6.x).
- Frontend:
  - Конфигурация, регистры (одиночная и пакетная запись — кнопка «Сохранить диапазон (batch)»), блок Modbus-сервер: статус (запущен/остановлен), кнопки «Запустить»/«Остановить»/«Обновить статус».
- Оркестрация и dev: Docker Compose, локальные тесты через `pytest` после `pip install -e .[dev]`.

**Ближайшие возможные шаги:**
- Профили конфигурации (несколько YAML), улучшение UX регистров, при необходимости — простая аутентификация для GUI.
