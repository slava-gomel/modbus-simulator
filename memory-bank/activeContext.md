## Active Context

**Текущий фокус (2026‑02‑10):**
- Улучшение наблюдаемости и UX: журнал событий Modbus (IP‑адреса, фильтры, экспорт) и удобное представление регистров (битовый вид и дополнительные форматы).

**Реализовано:**
- Backend:
  - ModbusSimulatorCore, Modbus TCP сервер (старт/стоп через API), REST API (config, state, batch, server status/start/stop, profiles), storage (config, state, profiles), lifespan вместо on_event, обработка «порт занят» при старте сервера, опциональная Basic Auth по env, модуль `modbus_log` с буфером событий.
  - Локальный форк части `pymodbus.server.async_io` (`patched_pymodbus_server`), позволяющий получать IP клиента для Modbus TCP соединения.
  - HEX‑трейсы запросов/ответов (`modbus_req_hex`/`modbus_rsp_hex`) теперь содержат IP клиента и унифицированный формат сообщений (`IP →/← HEX REQ/RSP unit=… func=… hex=…`).
  - Дополнительные события `client_connect`/`client_disconnect` с IP и причиной отключения.
- Frontend:
  - Конфигурация, регистры (одиночная и batch‑запись, пресеты «нули»/«случайные значения»), блок Modbus‑сервер (статус, Запустить/Остановить, автообновление статуса), профили (сохранение/загрузка/удаление).
  - Общий стиль (`styles.css`): тёмная тема, карточки‑панели, регистры по центру, журнал во всю ширину снизу.
  - Сетка регистров как в классических Modbus‑симуляторах: таблица с диапазонами адресов по строкам и колонками `+0…+9`, редактируемые ячейки для `coils` и `holding`.
  - Дополнительный «битовый» вид для `coils`: интерактивная сетка битов по 32 в строке, клик по квадрату переключает состояние и вызывает запись в соответствующий coil.
  - Для `holding`/`input` реализован выбор формата отображения регистров в едином блоке под панелью: INT16/32/64, FLOAT32/64 и BITMAP с отдельным выбором Signed/Unsigned и порядком слов ABCD/CDAB для 32/64‑битных форматов.
  - Для `holding` реализовано редактирование значений во всех форматах (INT16/32/64, FLOAT32/64, BITMAP) с учётом signedness, порядка слов, поддержкой ввода с точкой/запятой и экспоненциальной записи (например `2.5e3`), с безопасной обработкой промежуточных состояний ввода.
  - Экран логина и журнал событий приведены к единому виду, усилен контраст шрифтов на тёмном фоне.
  - Журнал событий: цветовая дифференциация типов, фильтры по типу (`Все/Modbus/Сервер/Ошибки`), фильтр по IP и общая строка поиска, экспорт текущего view журнала в JSON.
- Тесты: health, state API, batch, server API, profiles API; `conftest` с временным DATA_DIR.

**Дальше по желанию:** GitHub Actions (CI), расширенные тесты/e2e, дальнейшая доработка UX (быстрая навигация по страницам регистров, сохранение layout‑предпочтений, более продвинутая группировка запрос/ответ в журнале).
