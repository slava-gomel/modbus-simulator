## Active Context

**Текущий фокус (2026‑02‑10):**
- Редизайн WEB‑GUI под современный тёмный dashboard: таблица регистров в стиле классического Modbus‑симулятора, переработанный layout (регистры по центру на всю ширину, журнал снизу на всю ширину), улучшенная читаемость шрифтов.

**Реализовано:**
- Backend: ModbusSimulatorCore, Modbus TCP сервер (старт/стоп через API), REST API (config, state, batch, server status/start/stop, profiles), storage (config, state, profiles), lifespan вместо on_event, обработка «порт занят» при старте сервера, опциональная Basic Auth по env, модуль `modbus_log` с буфером событий и HEX‑трейс через `request_tracer`/`response_manipulator`.
- Frontend:
  - Конфигурация, регистры (одиночная и batch‑запись, пресеты «нули»/«случайные значения»), блок Modbus‑сервер (статус, Запустить/Остановить, автообновление статуса), профили (сохранение/загрузка/удаление).
  - Новый общий стиль (`styles.css`): тёмная тема, карточки‑панели, выравнивание регистров по центру, журнал во всю ширину снизу.
  - Сетка регистров как в классических Modbus‑симуляторах: таблица с диапазонами адресов по строкам и колонками `+0…+9`, редактируемые ячейки для `coils` и `holding`.
  - Экран логина и журнал событий приведены к единому современному виду, усилен контраст шрифтов на тёмном фоне.
- Тесты: health, state API, batch, server API, profiles API; conftest с временным DATA_DIR.

**Дальше по желанию:** GitHub Actions (CI), расширенные тесты/e2e, доработка UX (быстрая навигация по страницам регистров, сохранение layout‑предпочтений).
