## Active Context

**Текущий фокус работы:**
- Реализация минимально полезной версии Modbus TCP симулятора:
  - Один Modbus TCP slave с базовыми функциями 01/02/03/04/05/06.
  - WEB GUI для просмотра/редактирования регистров и базовой конфигурации.

**Состояние реализации:**
- Backend:
  - Есть `ModbusSimulatorCore` с in-memory областями регистров.
  - Modbus TCP сервер на базе `pymodbus`, связанный с ядром.
  - REST API `/api/config` и `/api/state/{kind}`.
  - Файловый storage (`config.yaml`, `state.json`) с автоматической загрузкой и сохранением.
  - Базовые автотесты (`/health`, чтение/запись holding и coils).
- Frontend:
  - Vite+React SPA.
  - Экран конфигурации (host/port/unit и размеры областей).
  - Экран регистров с возможностью чтения и одиночной записи для `coils` и `holding`.
- Оркестрация:
  - Dockerfile-ы для backend и frontend.
  - `docker-compose.yml` для совместного запуска и общего тома `/data`.

**Ближайшие возможные шаги:**
- Расширить поддержку Modbus-функций (множественная запись 15/16).
- Добавить работу с профилями конфигурации (несколько YAML-профилей).
- Улучшить UX фронтенда (группировка регистров, подсветка изменений, пресеты).
- Добавить простую аутентификацию к WEB GUI при необходимости.
